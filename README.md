# fishmarket-launcher.github.io

The FishMarket website, <https://fishmarket-launcher.github.io>, served by GitHub Pages from this repository.

`download/` holds the current Windows build (also attached to each [release](https://github.com/fishmarket-launcher/fishmarket-launcher.github.io/releases)). Fonts are Inter and JetBrains Mono under the SIL Open Font License (`assets/fonts/`); the "Made with Slint" badge links to <https://slint.dev>.
